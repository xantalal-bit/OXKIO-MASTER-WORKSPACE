# SIMULADOR IA

## Objetivo

Crear un sistema experimental dentro de Oxkio capaz de:

- simular escenarios
- analizar decisiones
- comparar estrategias
- utilizar múltiples IAs
- generar propuestas supervisadas
- ayudar a CEOs y empresas

---

## Filosofía inicial

El proyecto debe:

- ser modular
- no romper Oxkio
- funcionar separado inicialmente
- poder integrarse después
- ejecutarse de forma segura
- minimizar costes
- aprovechar APIs e IAs existentes

---

## MVP inicial

Versión mínima funcional:

1. interfaz simple
2. entrada de petición por texto
3. motor de simulación básico
4. respuesta estructurada
5. exportación de resultados
6. ejecución aislada

---

## Estructura inicial

- docs → documentación
- src → código
- tests → pruebas
- exports → resultados generados

---

## Integración futura con Oxkio

Posibles integraciones futuras:

- memoria Oxkio
- agentes IA
- approval center
- generación de informes
- decisiones empresariales
- simulaciones financieras
- análisis estratégico
