Centro de aprobaciones — Oxkio

Revisa y autoriza propuestas detectadas por el sistema antes de ejecutar acciones.

Flujo: Gmail OAuth → analyze → approval → execute-approved

  1. Usuario autoriza acceso vía Gmail OAuth; tokens se almacenan en backend.
  2. El motor analiza correos y publica propuestas con estado pending.
  3. Esta interfaz lista las propuestas desde /api/pending-approvals para revisión humana.
  4. Aprobar llama /api/approve?id=... y registrar auditoría.
  5. Ejecutar llama /api/execute-approved?id=... para finalizar la acción.
Auto-refresh cada 10s
